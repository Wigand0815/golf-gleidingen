# Golf Gleidingen – Web-App (PWA) für iPhone

iOS installiert Web-Apps nur von einer HTTPS-Adresse. Einmal hochladen, danach läuft die App offline.

## Hochladen (eine Möglichkeit: GitHub Pages, kostenlos)
1. Neues öffentliches Repository auf github.com anlegen, z. B. `gleidingen`
2. Alle Dateien dieses Ordners hochladen (Add file › Upload files)
3. Settings › Pages › Branch `main` / root › Save
4. Nach ca. 1 Minute ist die App unter `https://<name>.github.io/gleidingen/` erreichbar

## Auf dem iPhone installieren
1. Die Adresse in **Safari** öffnen
2. Teilen-Symbol › „Zum Home-Bildschirm“
3. App vom Home-Bildschirm starten, einmal mit Internet öffnen (lädt OSM-Daten und speichert die App offline)
4. GPS-Knopf tippen und Ortung erlauben

Funktioniert danach ohne Netz: Karte, GPS-Position, Entfernungen, Score.
